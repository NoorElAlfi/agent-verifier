## Decisions
- **Decision precedence.** Rows are evaluated in order, first match wins, strictest first:
  E1 authz error → defer; R1 OPA deny → reject; E2 any check/probe error or tier missing/out of
  0..4 → defer; R2 failed `block` check → reject; R3 failed probe → reject; R4 failed `escalate`
  check → require_human; R5 tier 3–4 → require_human; R6 tier 0 → accept_with_logging;
  R7 tier 1–2 → accept. The table is in `av/decide.py`'s docstring and `DECISION_TABLE`.
- **How checks signal drift/taint:** `CheckResult.severity`. B's ScopeDriftCheck returns `block`
  for protected-class drift and `escalate` for other drift; ProvenanceCheck returns `block`.
  `info` never changes a decision. decide() has no contract parameter at all.
- **Claims never leave the ledger path.** Policy, checks, probes, tier_fn and the oracle get
  `contract.without_claims()` (a deep copy with `agent_claims = {}`), so a component that mutates
  its params can't change what executes either.
- **Hash:** sha256 over canonical JSON (sorted keys, no whitespace, UTF-8, no NaN) of exactly
  `{tool, target, params}`. `target` is derived from params by ContractBuilder: `params.path`;
  `"."` for run_tests and for list_files without a path; `""` for submit.
- **Params per tool** are fixed in `TOOL_PARAMS` (all strings). Unknown tool/param, a missing
  param, or a tool not in `task.allowed_tools` → `ContractError`; the gateway returns it to the
  agent as a refusal and nothing executes.
- **derived_scope_ok** uses `basic_scope_ok` (conservative: any `..`, absolute path or backslash
  is out of scope; fnmatch where `*` crosses `/`). It's informational: B's ScopeDriftCheck is
  authoritative. ContractBuilder takes `scope_fn` and `tier_fn`, so the merge can inject B's.
- **Pipeline details:** snapshot = hashes of every file in the workspace (not just the target),
  taken before verification and re-taken right before execution; any change → re-verify (at most
  `max_reverify=1` times), then defer. The executor gets the same snapshot and is expected to
  re-check the target itself. Executor `refused` or an exception → defer. Probes run only if
  nothing has blocked yet and the tier's catalog entry lists them; a tier missing from the
  catalog or a listed probe not wired → defer. Outcome checks run only after execution; a
  failure is recorded in `outcome` and `reasons` (the decision is not rewritten, since the
  action already ran). A ledger failure raises (an unrecorded action must be loud).
- **require_human** asks the injected `HumanOracle`; `ScriptedOracle` denies unless its
  `approve(contract)` says yes. An oracle exception counts as a denial. The record keeps
  `final_decision=require_human` plus `human={responder, approved}`.
- **Quota:** `AV_DATA_DIR/quota.json` (filelock), counts total/day (UTC)/run (`AV_RUN_ID`) and
  tokens. `assert_budget(n)`: n > 100 needs `approved=` or `AV_APPROVED_CALLS`; daily cap 300 in
  every phase; in `AV_PHASE=post0` (default) total must stay < 200. HostedClient checks the
  budget before, and counts after, every call, including failed ones. `python -m av.quota` prints usage.
- **TaskDefinition.workspace** (default `examples/sample_repo`) added so scenarios name their repo.
  `Proposal.expect` (optional) lets fixtures state the expected decision; replay may assert on it,
  it never feeds the pipeline.
- **conftest** also blocks non-loopback sockets and never loads `.env`.
- `new_worktree.sh` also symlinks `bin/` (OPA) from the main checkout into the worktree.
- **After code review:** `Pipeline.tier_fn` (set it to B's assign_tier) recomputes the tier from
  the claims-free view and overrides `contract.risk_tier`; `Pipeline.run()` turns any unexpected
  exception into a ledgered defer; `ContractBuilder.build()` wraps taint/scope/tier failures in
  `ContractError`; `assert_budget` also gates the running total of the current `AV_RUN_ID`
  above 100 calls without an approved cap.
- **Known, accepted:** quota check and record lock separately (parallel runs can overshoot by a
  few calls); a ledger failure after execution raises, leaving an executed action unrecorded
  (loud by design); the conftest network guard doesn't block DNS lookups (real clients raise anyway).
